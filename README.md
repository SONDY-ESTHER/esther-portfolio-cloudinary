# Esther's Portfolio — Galerie Cloudinary

## Présentation
Esther's Portfolio est un site web responsive qui présente une galerie de trois images hébergées sur Cloudinary et chargées à partir de leurs URL publiques.

## Technologies utilisées
- HTML5
- CSS3
- JavaScript
- Cloudinary

## Utilisation de Cloudinary
Les trois images sont hébergées dans la bibliothèque Cloudinary. Leurs URL publiques sont intégrées dans le tableau `photos` du fichier `script.js`. Les images ne sont pas stockées dans le dossier du projet. Aucun API secret Cloudinary n'est utilisé dans ce site statique.

## Exécuter le projet localement
1. Téléchargez ou clonez le dépôt.
2. Ouvrez le dossier du projet.
3. Ouvrez `index.html` dans un navigateur.
4. Les trois liens Cloudinary sont déjà configurés dans `script.js`.

## Publication avec GitHub Pages
1. Envoyez les fichiers du projet dans un dépôt GitHub.
2. Ouvrez **Settings > Pages**.
3. Sous **Build and deployment**, choisissez **Deploy from a branch**.
4. Sélectionnez la branche `main` et le dossier `/ (root)`, puis enregistrez.
5. Après publication, copiez l'adresse publique affichée.

Lien du site publié : à compléter après le déploiement.

## Vérification
Vérifiez que les trois images s'affichent sur ordinateur et téléphone et qu'elles sont accessibles aux visiteurs sans connexion à Cloudinary.
